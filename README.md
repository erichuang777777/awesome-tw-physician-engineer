## 這是什麼

這是一份**非官方名冊**，彙整台灣仍在臨床／醫療第一線、同時有軟體開發、資料工程、AI／ML、產品或開源貢獻的公開帳號與專案，方便交流與合作。

本頁採隱私優先：主表以 **GitHub login（連結）** 為識別，不以完整中文姓名或醫院作為主要欄位；不主動推測或拼接個人身分。姓名只有在本人於 GitHub 個人檔案或個人網站明確自我公開時才會考慮補充，否則省略或標示「公開名待確認」。醫院／院所資訊不放在主表；任何補充院所資訊都必須標示「待本人確認／公開來源」。

> **重要聲明**：本列表非官方名冊；內容彙整自公開來源，可能過時或有誤。錯誤、過時、希望修改或想移除自己的條目，請開 [Issue](https://github.com/erichuang777777/awesome-tw-physician-engineer/issues)。建議本人以 opt-in 方式補充本名／醫院與其他公開資訊。

## 收錄原則

- **臨床第一線**：原則上收錄現職醫院／診所或其他臨床第一線的醫事人員；已轉為純工程、全職創業或其他非臨床現職者，暫不納入。
- **醫療產出**：需有公開可查、以醫療／健康／臨床／生醫為主題的開發成果，例如 GitHub 專案、開源工具、產品、論文程式碼或技術寫作。
- **公開與 opt-in**：只使用本人公開的帳號／專案資訊；姓名、院所與詳細 bio 以本人明確自我公開或主動 opt-in 為準，不從零散來源推測身分。
- **排序**：依 GitHub login 或公開常用 handle 的拼音／字母排序。
- **不以 commit 數作門檻**：重點是臨床脈絡與可查的醫療技術產出。

## 如何推薦、修正或移除

請開 [Issue](https://github.com/erichuang777777/awesome-tw-physician-engineer/issues) 或 Pull Request。推薦時建議只提供本人願意公開的資訊：

1. GitHub 或個人網站連結
2. 粗略專科／職類（可省略）
3. 代表醫療／健康相關專案
4. 一句收錄理由（選填）
5. 若希望 opt-in 顯示本名、醫院或其他 bio，請明確註明可公開範圍

任何人都可以提出錯誤、更正或移除要求；移除要求會優先處理。詳細 bio 與院所欄位原則上待本人確認後才補充，並標示「待本人確認／公開來源」。
