## 這是什麼

台灣有不少醫師同時具備軟體開發、資料工程、AI／ML、產品或開源貢獻能力。這個列表用來彙整公開可見、可查核的人物與專案，方便交流與合作。

收錄原則（暫定）：

- 身分：台灣相關之醫師
- 能力：有公開可查的開發成果（GitHub、開源專案、產品、論文程式碼、技術寫作等）
- 公開：僅收錄本人公開資訊或經同意分享的連結

## 如何推薦

歡迎開 [Issue](https://github.com/erichuang777777/awesome-tw-physician-engineer/issues) 或 Pull Request，請附上：

1. 姓名（公開慣用名）
2. 專科／身分
3. 開發向連結（GitHub、個人站、代表專案）
4. 一句話簡介（選填）
