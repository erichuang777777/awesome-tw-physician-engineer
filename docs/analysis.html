五、共同模式與缺口

大家常用的做法

  • 繞過 HIS、不改 HIS：瀏覽器擴充、熱鍵常駐、AutoHotKey、畫面疊圖。
  • 純前端單檔／靜態網站（GitHub Pages、Cloudflare、Vercel）：資料不離開瀏覽器，順便避開資安審查。
  • Claude skill 與 MCP 爆量：把指引、計算機、文獻庫包成 AI 工具。
  • 政府開放資料整理成 JSON 快取：健保、TFDA、ICD。
  • 隱私設計：本機模型、遮罩出錯一律擋下（fail-closed）。

還沒人在做（或做得少）

  • 沒有共用的台灣基礎元件：健保雲端解析、民國日期、身分證規則、ICD 對照各寫一份。
  • 去識別缺評估資料：沒有公開的台灣病歷 PHI 標註資料集或 benchmark。
  • 病房流程空白：交班、出院準備、會診追蹤、危險值追蹤幾乎沒人做。
  • 病人端少：多語衛教、長照銜接、用藥順從。
  • 品質與授權：多數 repo 沒有測試、臨床驗證或授權說明。
  • 其他職類：護理、藥師工作流程工具偏少。
